# TripFlow — Frontend

React 19 + Vite single-page app for the TripFlow API. See the
[root README](../README.md) for the full project documentation.

```bash
cp .env.example .env   # VITE_API_URL=http://localhost:5000/api
npm install
npm run dev            # http://localhost:5173
npm run build          # production build into dist/
npm run lint           # oxlint
```
